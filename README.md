# 全开源即时通讯源码系统（php即时聊天im源码）及uniapp开源框架 

源码地址：ym7k.com/17811/

这套基于 PHP 后端、UniApp 前端框架打造的全开源即时通讯 IM 系统，主打私有化部署的即时聊天能力，依托 UniApp 跨端特性，一套前端工程可以同时适配微信小程序、H5、移动端 APP 等多端入口，后端采用 PHP 架构，全部源码无加密开放，方便使用者自主部署、二次调整，可用于搭建私域客服沟通、社群交流、内部办公聊天、用户一对一咨询等多种场景，摆脱第三方 IM 平台的接口限制与流量管控。

一对一私聊是系统的基础通讯功能。用户之间可以发起单独会话，支持文字消息、表情、图片、文件、短视频发送，消息实时推送，支持消息已读、未读状态标记，消息记录云端持久保存，用户切换设备登录之后，能够正常加载历史聊天记录，不会出现记录丢失的问题。同时支持消息撤回功能，发送方在限定时间内可以撤回失误发送的内容，提升沟通容错性。

系统内置群组聊天模块，支持用户自主建群、管理员创建内部群聊。群主拥有群管理权限，可以设置群名称、群公告、群头像，进行成员邀请、移出成员、设置禁言、开启全员审核等操作。群消息同步下发给所有在线成员，同样支持图文、文件等多种消息格式。可以区分普通用户群和内部工作群，灵活适配客户社群、团队沟通等不同需求。

好友与关系链管理模块完善。用户可以发送好友申请，附带验证信息，对方审核通过后建立好友关系，支持好友备注、分组管理，可对好友设置消息免打扰，拉黑不需要沟通的用户，屏蔽对方消息，打造干净的通讯录列表。通讯录支持搜索，方便快速查找好友和群组。

后台管理模块由 PHP 后端承载，管理员可以查看全部注册用户列表，管理账号状态，封禁违规账号，查看所有会话记录，便于合规管控。后台可以配置消息相关参数，调整文件上传大小、图片压缩规则、撤回时效等。同时具备在线用户监控功能，实时查看当前在线人员，统计活跃数据，还可以分配多级子账号，给到客服、运营人员不同管理权限，实现多人协同维护。

依托 UniApp 跨端框架的优势，前端界面可以统一开发，同步上线多端，UI 布局适配手机屏幕，操作逻辑贴合主流聊天软件的使用习惯，用户上手简单。消息通知机制完善，离线状态下可以接收消息提醒，避免错过重要沟通。系统支持自定义头像、个人资料、个性签名，用户可以完善自己的主页信息。

作为全开源版本，整套源码开放可修改，运营者能够根据自身业务叠加功能，比如对接商城、表单、会员系统，实现客服 IM 联动。系统不绑定第三方通讯服务商，所有数据自主存放，数据私密性更强，适合重视数据自主管控的项目。

整体来说，这套 PHP+UniApp 组合的开源 IM 系统，覆盖私聊、群聊、好友管理、消息存储、后台管控等即时通讯核心能力，兼顾多端访问能力，开源特性降低定制门槛，是搭建私有化即时沟通工具的轻量化方案。
